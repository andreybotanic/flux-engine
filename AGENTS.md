# AGENTS.md

- Любую задачу начинай с чтения `game_overview.md`. Если в постановке задачи есть расхождения с game_overview - спрашивай, нужно ли доработать game_overview в соответствии с новыми данными или пользователь ошибся, и тогда нужно скорректировать постановку задачи в соответствии с game_overview.
- После завершения любой задачи все значимые изменения фиксируй в `game_overview.md`.
- После завершения любой задачи выполняй `cargo build --release`.
