# Changelog

## 2026-05-04
- Локальная подсветка сетки у курсора больше не мешает UI: при наведении на панели подсветка корректно скрывается.
- Упрощена визуальная консистентность Debug Panel: унифицирован цвет текста.

## 2026-05-03
- Выполнен крупный рефактор UI-панелей: общий модуль панелей, сворачивание, стекинг по углам, корректный hit-test и прокрутка.
- Улучшен UX взаимодействия с панелями: устранены мерцания/смещения и конфликты ввода между UI и камерой.
- Существенно улучшено поведение газовой плавучести в сложной геометрии (учёт достижимости и барьеров), добавлены регрессионные проверки.

## 2026-05-02
- Газовая симуляция переведена на дискретную particle-модель с строгим сохранением массы.
- Разделены `Main Menu` и `Game Menu`, улучшены сценарии старта без мира и поведение `Esc`.
- Добавлен полноценный поток сохранения/загрузки мира со слотами и подтверждением действий при несохранённых изменениях.
- Введена конфиг-система на TOML и поддержка динамического набора газов, добавлен `CO2`.

## 2026-05-01
- Добавлен переключаемый backend симуляции `CPU/GPU` и крупная доработка GPU-пути.
- Выполнен большой UI-рефактор редактора (инструменты, меню, поведение HUD, визуальные улучшения).
- Улучшены камера и читаемость сетки/оверлеев (включая якорный zoom под курсором).
- Расширены диагностические инструменты симуляции и производительности.

## 2026-04-30
- Развита газовая симуляция и визуализация: улучшена устойчивость, поведение слабых концентраций и контроль параметров через Debug Panel.
- Усилена инфраструктура тестирования и отладки для численной стабильности и качества поведения газа.

## 2026-04-29
- Реализован базовый набор инструментов редактора мира и газа.
- Добавлен `.gitignore` и исправлены ранние runtime-конфликты UI/ввода.
