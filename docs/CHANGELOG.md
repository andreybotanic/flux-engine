- Выполнен структурный рефактор `editor`: крупные блоки вынесены из монолитного `src/editor/mod.rs` в отдельные файлы внутри `src/editor/` без изменения игрового поведения.

- Добавлен и применён единый стиль документирования API: `Rustdoc` (`///`) обязателен для всех `pub struct` и `pub fn` в `src`.
- Доработан GPU-регрессионный тест `wall_adjacency_gpu_does_not_create_systematic_concentration_drop`: добавлен сценарий запертой комнаты (`3x3`, `5x5`, `9x9`) с `100` единицами газа на клетку и `100` шагами для явного контроля просадки концентрации в углах.
- Исправлено перераспределение blocked-потока в углах: при одном доступном тангенциальном направлении половина веса остается в `stay`, что убирает систематическое обеднение угловых клеток (правка синхронно внесена в CPU и WGSL GPU).

## 2026-05-04
- Добавлены клеточные газовые структуры `Gas Source` и `Gas Sink` с отдельными инструментами, иконками и тайлами.
- Добавлено редактирование поставленных Source/Sink при отсутствии выбранного инструмента, с подсветкой редактируемой структуры и закрытием режима редактирования по `Esc`.
- Улучшен UX постановки Source/Sink: под курсором отображается силуэт создаваемой клетки, а успешная постановка автоматически выбирает структуру для редактирования.
- Панель настроек структур теперь скрыта, пока не выбрана конкретная структура.
- Для `Add Gas` и `Gas Source` выбор газа переведен на dropdown/select вместо циклической кнопки.
- Визуальный стиль dropdown выбора газа обновлён под HTML-like `select`: белое поле со стрелкой, список опций с hover/selected состояниями.
- Исправлен UI dropdown: стрелка переведена на ASCII-символ, список опций вынесен в overlay-слой с повышенным `z-index` без роста высоты панели, подпись `Source gas` вынесена отдельной строкой над селектом.
- Стрелка dropdown переведена на отдельный спрайт `assets/sprites/ui/select_arrow.png`; при раскрытии селекта спрайт автоматически переворачивается.
- Добавлено сворачивание раскрытого селекта по клику в панели вне зоны опций/кнопки селекта.
- Для не-скроллируемых панелей включен `overflow: visible`, чтобы блок опций селекта не обрезался на границах панели.
- Логика dropdown-селекта вынесена из `editor` в отдельный модуль `ui/select_field` с собственным состоянием, системами обработки и тестами.
- Добавлена pre-step фаза симуляции для Source/Sink (инъекция и пропорциональное поглощение) с детерминированным округлением.
- Расширен save/load: добавлен отдельный chunk `gas_structures`, snapshot структур и повышение schema version до `2`.
- Расширены тесты по редактору, симуляции Source/Sink, save/load и parity-сценариям CPU↔GPU.
- Восстановлен рабочий runtime-путь GPU симуляции: шаги выполняются через `GpuGasSolver`, состояние синхронизируется readback-ом в `GasField`.
- Политика backend зафиксирована на старте процесса: дефолт `GPU`, fallback в `CPU` только при недоступности GPU на инициализации, без runtime-переключения.
- При runtime-ошибке в зафиксированном GPU backend включено fail-fast поведение: подробный error-лог и аварийное завершение приложения.
- Добавлен модуль `simulation::parity`: сравнение CPU/GPU через локальные средние концентрации, два фиксированных сценария (включая сценарий с дополнительными стенами), долгий parity-прогон на 5000 шагов и отдельная ручная CPU-only калибровка (`#[ignore]`).
- Обновлен `gas_perf`: добавлен parity-gate перед preflight/full-run, зафиксированы обязательные размеры `502x502` и `1002x1002`, формализованы критерии приёмки speedup.
- `gas_perf` теперь запускается только в release-профиле; в отчёты добавлена метка времени старта прогона (UTC).
- Из CPU-части perf-прогонов убрана float/LBM perf-модель: тесты производительности переведены на дискретную модель газа.
- Дискретный шаг вынесен в общий модуль `simulation::discrete_step`; `gas_perf` теперь вызывает тот же код шага, что и runtime CPU, без отдельной копии алгоритма.
- Локальная подсветка сетки у курсора больше не мешает UI: при наведении на панели подсветка корректно скрывается.
- Упрощена визуальная консистентность Debug Panel: унифицирован цвет текста.
- Локализована причина падения shader pipeline в WGSL: опасный паттерн `weighted_pick` с loop/index по `array<f32,5>` заменён на scalar/unrolled `weighted_pick5`, добавлены комментарии-ограничения в шейдер.
- Удалены дубли backend-логики: из компиляции исключен legacy `simulation::perf_model`, убраны неиспользуемые LBM-копии и вспомогательные дублеры шага из `gas.rs`.
- Для GPU шага оставлен один режим исполнения (`runtime_transfer`): удален альтернативный `forced_full_readback` из solver/perf-пайплайна.
- Синхронизировано правило blocked-neighbor для CPU и GPU: закрытые клетки исключаются из вероятностного распределения (вес `0`), перенос в них не выполняется; после правки долгий parity `CPU vs GPU` (2 сценария × 5000 шагов) снова проходит.
- GPU solver приведен к CPU-эталону по ключевой математике: в WGSL перенесен buoyancy-контекст и исправлена инициализация RNG (`seed ^ 0x9E37_79B9`) для совпадающего stochastic-step поведения.
- Убрана float-упаковка species в GPU: хранение и readback переведены на `u32` flat-buffer, что исключает расхождения от `round/clamp` на каждом шаге.
- Снято ограничение GPU на 3 газа: `gas_count` и молекулярные массы теперь передаются динамически (от `GasField`) через отдельный буфер масс.
- Обновлена модель blocked-направлений в CPU и GPU: поток в закрытое направление не выполняется, его вес перераспределяется вдоль стены (по двум тангенциальным направлениям), при полном блоке вес уходит в `stay`.
- Добавлен GPU-регрессионный тест `wall_adjacency_gpu_does_not_create_systematic_concentration_drop` для контроля отсутствия систематического обеднения концентрации у внутренних стен.
- Исправлено управление временем симуляции: режимы `x2/x5` больше не делают несколько итераций в одном тикe; теперь всегда выполняется один шаг за тик, а ускорение достигается повышением частоты тиков `FixedUpdate`.
