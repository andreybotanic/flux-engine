# Changelog

## 2026-05-06
- Добавлен единый каталог `config/structures/*.toml` для appearance-метаданных стен и структур: размер в клетках и `draw_priority` теперь грузятся из TOML, а основной render-order больше не задаётся специальными условиями в коде.
- Исправлен `F3`-рендер pipe-индикаторов при создании и выборе `Gas Source` / `Gas Sink`: одинаковые параметры структуры больше не переустанавливаются каждый кадр, а порядок pipe-render систем зафиксирован явно, поэтому квадраты газа в трубах не пропадают при открытии редактора структуры.
- Исправлено drag-построение труб: новые pipe-соединения теперь создаются только вдоль фактической линии штриха, поэтому вертикальная труба в зазоре между двумя горизонтальными больше не склеивает их автоматически по бокам.
- Исправлена вертикальная ориентация pipe-mask спрайтов: render-mask снова использует тот же `up/down` bit-contract, что и файловые `pipe_mask_*` ассеты, поэтому трубы больше не выглядят перевёрнутыми по вертикали.
- Исправлен контракт размеров preview/спрайтов структур: размер в клетках теперь вычисляется через descriptor-модель, поэтому обычные объекты снова рендерятся как `1x1`, а мост остаётся единственным `3x1/1x3`.
- Исправлен UI/рендер моста: добавлена отдельная иконка `tool_bridge.png`, ghost-preview теперь действительно поворачивается, а установленный вертикальный мост больше не деформируется из-за одновременного поворота и ручного ресайза.
- Введён единый runtime-реестр `PlacedStructureMap` и layer-driven descriptor-механизм для труб, вентиляций, Source/Sink и многоклеточных структур; сохранена backward-compatible миграция старых schema `3` сейвов.
- Добавлен `Gas Pipe Bridge`: многоклеточная структура `1x3/3x1` с поворотом по `R`, собственным pipe-объёмом в центральной клетке, overlay-соединениями на краях и отдельными спрайтами `bridge.png` / `bridge_silhouette.png`.
- Pipe-система переведена на node-based хранение газа (`PipeNodeKey`, `BridgePipe`), поэтому обычная труба и труба моста теперь могут сосуществовать в одной клетке без автоматического смешивания.
- Обновлён `F3`: bridge-края используют тот же `gas_in_out` overlay, а клетки с двумя pipe-контейнерами показывают два отдельных квадрата газа и отдельные HUD-блоки.
- Исправлено ложное движение pipe-packets сразу после снятия с паузы на низкой частоте симуляции: stale `PipeFlowVisualState` теперь очищается на переходе `paused ↔ running`, поэтому до первого нового fixed-tick не показываются пакеты прошлого шага.
- Исправлен краткий визуальный “заливочный” всплеск труб при старте симуляции: статический квадрат газа в `F3` и HUD теперь показывают только persistent pipe-содержимое, а transient transfer state остаётся только в отдельной анимации moving packets.
- Исправлено деление потока на `T`/`X`-разветвлениях pipe-сети: общий исходящий объём узла теперь считается один раз на всю развилку и только потом делится по downstream-дефицитам, поэтому перекрёстки с несколькими вентиляциями больше не опустошаются целиком за один тик.
- Pipe-сеть переведена с глобального solver-а по вентиляциям на локальную синхронную клеточную симуляцию: одна вентиляция теперь может заполнять пустую трубу, `world↔vent` использует порог `5`, а перенос `pipe↔pipe` идёт по локальному перепаду соседних сегментов с single-hop double-buffer логикой.
- Уточнено семейство `gas_in_out` / `gas_in` / `gas_out`: хвост стрелки теперь чуть глубже заходит в наконечник для чистого стыка, а чёрный outline стрелок сделан немного тоньше.
- Исправлен контур наконечников в `gas_in_out` / `gas_in` / `gas_out`: black outline теперь строится по той же маске стрелки, поэтому угол и положение границы совпадают с цветной формой без смещения.
- Перерисовано семейство overlay-спрайтов `gas_in_out` / `gas_in` / `gas_out`: у квадрата теперь есть явный чёрный контур и по внешней, и по внутренней границе, а у стрелок контур повторяет форму самой стрелки вместо эффекта второй фоновой стрелки.
- `gas_in_out.png` перерисован в том же стиле, что и `gas_in`/`gas_out`: верхняя и нижняя стрелки теперь используют согласованную форму головок и хвостов.
- Подправлена геометрия overlay-спрайтов `gas_in.png` и `gas_out.png`: у `gas_in` хвост стрелки теперь продолжается снаружи квадрата, а у `gas_out` уходит внутрь квадрата при сохранении общего шаблона рамки.
- Семейство `gas_in_out` / `gas_in` / `gas_out` переведено на размер `256x256` для более чистого сглаживания и дальнейшего удобства в рендере.
- Обновлено семейство overlay-спрайтов вентиляции для `F3`: `gas_in_out.png` получил более тонкую сглаженную стрелку, добавлены согласованные варианты `gas_in.png` и `gas_out.png`, а silhouette для этой иконки удалён как ненужный.
- `F3`-иконка вентиляции перегенерирована через `imagegen` как отдельный сглаженный world-спрайт `gas_in_out.png`; добавлена silhouette-пара `silhouette_gas_in_out.png`.
- Перерисован `tile_vent_overlay_f3.png`: квадрат стал толще, а по квадрату и стрелке добавлен чёрный контур для лучшей читаемости в `F3`.
- `F3`-иконка вентиляции переведена с procedural runtime-рисования на отдельный файловый world-спрайт `tile_vent_overlay_f3.png`.
- Для pipe-сети повышен порог активации вентиляций до `5` частиц, чтобы слабые перепады давления ещё реже вызывали мелкие колебания потока.
- Смягчено отображение малых flow-пакетов в `F3`: у движущегося газа теперь только внутренняя цветная часть меняет яркость и прозрачность по объёму переноса, а белая рамка остаётся полностью непрозрачной.
- Исправлено ложное “самозаполнение” труб при строительстве на паузе: HUD и статический `F3` больше не подмешивают stale flow-пакеты прошлого тика, а редактирование pipe-сети сбрасывает старый transient-flow state.
- Снижено сопротивление труб: коэффициент проводимости `PIPE_FLOW_CONDUCTIVITY` увеличен до `1.9`, поэтому газ заметно легче продвигается по длинным участкам pipe-сети без мгновенного выравнивания коротких прямых линий за один тик.
- Для pipe-сети введён порог активации вентиляций 3 частицы: слабые пары не создают поток, а вентиляции с почти равным давлением больше не запускают мелкие колебания туда-сюда.
- Усилена пропускная способность труб: в расчёт потока добавлен коэффициент проводимости, чтобы длинные трубы теряли меньше эффективности из-за распределения перепада давления по длине.
- Убрано мгновенное распространение газа по всей pipe-сети за один тик: теперь газ двигается по трубе пошагово, по одному соседнему участку за simulation tick, а труба заполняется фронтом от входной вентиляции.
- В F3 квадраты газа внутри труб и движущиеся пакеты теперь масштабируются по фактическому количеству газа и рисуются с белой обводкой.
- HUD инспектора клетки расширен: при наведении на трубу он показывает отдельный блок с составом газа внутри трубы и суммарным заполнением Pipe total.
- Исправлен startup panic в `sync_pipe_overlay_visuals`: конфликтующие запросы видимости переведены на безопасный `ParamSet`.
- Исправлено отображение заполнения трубы во время активного потока: HUD и `F3` теперь учитывают и transient flow-пакеты, поэтому газ в движущейся трубе больше не выглядит как постоянные `0 / 1000`.
