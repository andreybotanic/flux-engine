# Этап 3: экран Plugins в главном меню

## Проверка предпосылок

Перед началом этапа убедиться:
- этап 2 завершён;
- есть `PluginSourceRegistry`, `LoadedPluginRegistry`, `EnabledPluginSet`;
- default plugin представлен как locked enabled item;
- состояние плагинов можно читать из Bevy resources.

Если registry state ещё не готов, UI не начинать.

## Будущие зоны изменений

Ожидаемые зоны кода:
- `src/save.rs`: добавить новый `MainMenuScreen::Plugins`;
- `src/editor/mod.rs`: добавить action-типы для открытия plugins screen и toggle;
- `src/editor/ui_setup_setup_fn_block.rs`: добавить кнопку `Plugins` и UI-контейнер экрана;
- `src/editor/main_menu_ui_block.rs`: видимость нового экрана;
- `src/editor/main_menu_actions_block.rs`: обработка открытия и toggles;
- `src/editor/main_menu_escape_block.rs`: возврат из экрана plugins;
- `docs/game_overview.md`;
- `docs/project_structure.md`.

## Что реализовать

1. В `Main Menu` добавить пункт `Plugins`.

2. Экран `Plugins` должен показывать список плагинов и переключатели:
   - display name;
   - version;
   - `On/Off`;
   - disabled toggle для default plugin.

3. Не добавлять сложный менеджер зависимостей на этом этапе. MVP экрана - список и переключатели.

4. Переключение разрешать только когда мир не загружен:
   - в `MainMenuMode::Main` до `New Game/Load` - можно;
   - если мир загружен или открыт `Game Menu` - переключатели disabled.

5. При включении/выключении обновлять `EnabledPluginSet` и запускать безопасную перезагрузку registry state без world runtime state.

6. Если плагин сломан, показывать его в списке как недоступный для включения. Не скрывать сломанные записи: пользователю нужно видеть, что пакет найден, но невалиден.

7. Главное меню должно продолжать полностью перехватывать ввод мыши и клавиатуры.

## Edge cases

- Список плагинов пустой кроме default plugin.
- Плагин найден, но manifest invalid.
- Пользователь пытается выключить default plugin.
- Пользователь быстро кликает toggle несколько раз.
- Пользователь открывает `Plugins`, затем `Load`, затем возвращается назад.
- При активном мире экран открыт через `Game Menu`: toggles должны быть disabled.

## Тесты этапа

Запускать только связанные editor/menu tests:
- `Plugins` screen открывается из root main menu;
- default plugin отображается и не отключается;
- toggle disabled при загруженном мире;
- toggle меняет `EnabledPluginSet`, когда мир не загружен;
- `Esc` или `Back` возвращает на root screen.

После этапа выполнить `cargo build --release`, запустить release-версию и проверить:
- `Main Menu -> Plugins` открывается;
- default plugin нельзя отключить;
- приложение стартует без ошибок.

## Заметка для заказчика

Запусти игру и на главном экране открой `Plugins`. В списке должен быть `flux.default` с выключенным/заблокированным переключателем: его нельзя отключить. Если рядом есть тестовый внешний плагин, попробуй включить и выключить его переключателем, затем вернуться назад и снова открыть `Plugins`: выбранное состояние должно сохраниться. После `New Game` открой игровое меню и проверь, что переключатели больше нельзя менять, пока мир загружен.

## Критерии успешности

- Пользователь видит экран `Plugins`.
- Плагины можно включать и выключать до загрузки мира.
- Default plugin нельзя отключить.
- UI не обещает загрузку мира с отсутствующим content до этапа save-gate.
